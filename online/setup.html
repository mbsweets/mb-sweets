🌐 ऑनलाइन ऑर्डर सेटअप

MB Sweets — सिर्फ एक बार करना है (करीब 15 मिनट)

1नई Google Sheet बनाएं

💻 यह काम कंप्यूटर/लैपटॉप पर सबसे आसान है। फोन पर करना हो तो Chrome में ऊपर ⋮ → "Desktop site" ✓ चालू कर लें, और Google Sheets ऐप की जगह Chrome में ही खोलें।

  1. नीचे वाला बटन दबाएं — अपने Google अकाउंट (वही Gmail जो आप चलाते हैं) से एक खाली शीट खुलेगी।
  2. ऊपर शीट का नाम बदलकर MB Sweets ऑनलाइन ऑर्डर कर दें।
📄 नई Google Sheet खोलें

2कोड चिपकाएं

  1. शीट में ऊपर मेन्यू: Extensions (एक्सटेंशन) → Apps Script
  2. नया पेज खुलेगा, उसमें पहले से लिखा थोड़ा सा कोड होगा — उसे पूरा मिटा दें।
  3. नीचे "📋 कोड कॉपी करें" दबाएं और वहाँ चिपका (Paste) दें।
  4. ऊपर 💾 (Save) दबाएं।
  5. ऊपर ▶ Run दबाएं (बगल में setupSheet लिखा होगा) → Review permissions → अपना Google अकाउंट चुनें।
  6. "Google hasn't verified this app" आए तो घबराएं नहीं — यह आपका अपना बनाया कोड है। नीचे Advanced → Go to … (unsafe) → Allow दबाएं। नीचे "Execution completed" दिखे तो ठीक है।
कोड देखें (कॉपी न हो तो यहाँ से पूरा चुनकर कॉपी करें)

3Deploy (चालू) करें

  1. ऊपर दाईं ओर नीला बटन Deploy → New deployment
  2. ⚙️ (Select type) → Web app
  3. Execute as: Me  ·  Who has access: Anyone
  4. Deploy दबाएं। (अगर फिर से Authorize access पूछे तो चरण 2 वाली तरह Allow कर दें।)
  5. आखिर में Web app URL दिखेगा (https://script.google.com/macros/s/…/exec) — उसे Copy करें।

4बिलिंग ऐप से जोड़ें

Web app URL यहाँ चिपकाएं और "जोड़ें" दबाएं। यह काम उसी फोन पर करें जिसमें आपका बिलिंग ऐप है। (चरण 1–3 कंप्यूटर पर किए हैं तो URL WhatsApp पर खुद को भेजकर फोन में कॉपी कर लें, और यह पेज फोन पर खोलें।)

यह शीट पहले ही जुड़ चुकी है। पुराने फोन पर सेव किया "सेटअप लिंक" खोलें, या वहाँ दिखी चाबी यहाँ लिखें:

5फोन पर नोटिफिकेशन (ntfy ऐप)

  1. Play Store से ntfy ऐप डालें। Play Store पर खोलें
  2. ntfy खोलें → नीचे + दबाएं → Topic name में यह नाम डालें:
    — पहले चरण 4 पूरा करें —
  3. Subscribe दबाएं। अगर पूछे तो "Instant delivery" चालू करें और नोटिफिकेशन की अनुमति दें।
  4. फोन की Settings → Apps → ntfy → Battery → Unrestricted / Don't optimise कर दें, ताकि नोटिफिकेशन देर से न आए।

6Claude को URL भेजें

ग्राहकों वाला मेन्यू इस रजिस्टर से जोड़ने के लिए Claude को सिर्फ Web app URL चाहिए (गुप्त चाबी नहीं)।

🔐 सेटअप लिंक — दूसरे फोन में जोड़ना हो या फोन बदले, तो इस लिंक से दोबारा जुड़ जाएगा। इसे सिर्फ अपने पास रखें (खुद को WhatsApp कर दें), किसी और को न भेजें।

7🥛 दूध-दही रिमाइंडर

रोज़ दोपहर करीब 2 से 2:30 के बीच फोन पर (ntfy) घंटी: परसों की मिठाई के लिए कितना दूध (1 किलो = 2 लीटर) और कल का दही/दूध/पनीर।

नया सेटअप अभी किया है (चरण 1–6)? तो यह पहले से चालू है — बस नीचे "जांचें" दबाएं।
पहले से चल रहा सेटअप है तो कंप्यूटर पर एक बार कोड अपडेट करना है (5 मिनट):

  1. वही Google Sheet खोलें (MB Sweets ऑनलाइन ऑर्डर) → Extensions → Apps Script
  2. पुराना कोड पूरा मिटाएं (Ctrl+A फिर Delete) → ऊपर चरण 2 का "📋 कोड कॉपी करें" दबाकर नया कोड चिपकाएं → 💾 Save
  3. ऊपर ▶ Run दबाएं (बगल में setupSheet लिखा हो)। नई अनुमति माँगेगा → Review permissions → अकाउंट चुनें → Advanced → Go to … (unsafe) → Allow। नीचे "Execution completed" दिखे तो ठीक।
  4. ऊपर Deploy → Manage deployments → ✏️ (पेंसिल) → Version: New version → Deploy। URL वही रहेगा — कहीं कुछ बदलना नहीं है।

⚠️ क्रम यही रखें — पहले Run (अनुमति), फिर Deploy। "New deployment" मत दबाना, वरना URL बदल जाएगा।
